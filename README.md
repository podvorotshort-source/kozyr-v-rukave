# Козырь в рукаве — дурак-рогалик

Браузерная игра: подкидной дурак против девяти соперников. Между партиями игрок покупает талисманы (постоянные бонусы) и фокусы (разовые хитрости). Забег состоит из трёх актов: «Двор», «Электричка» и «Подпольный клуб». В конце каждого акта ждёт босс со своим особым правилом.

Вся игра — один HTML-файл без сторонних библиотек. Работает на компьютере и на телефоне.

## Как запустить

- **Просто поиграть:** откройте `dist/index.html` в браузере (Chrome, Edge, Яндекс Браузер).
- **Пересобрать после правок:** `python build.py`. Сборщик склеивает файлы из `src/` в `dist/index.html` (полная страница) и `dist/artifact.html` (версия для публикации артефактом Claude).

## Что внутри

| Файл | Что в нём |
|---|---|
| `src/engine.js` | Правила дурака: раздача, атака, защита, подкидывание, перевод, добор, конец партии |
| `src/ai.js` | Соперник. Параметр «ум» от 0 до 1 задаёт, насколько хорошо он играет |
| `src/content.js` | Талисманы, фокусы, соперники и их правила, рубашки колоды |
| `src/run.js` | Забег: сохранения, правила стола, награды, барахолка |
| `src/ui.js` | Интерфейс, анимации, звуки, экраны |
| `src/style.css` | Оформление |
| `tests/` | Проверки на Node.js (описаны ниже) |

Новый талисман, фокус или соперник добавляется одним объектом в `src/content.js`, движок трогать не нужно.

## Проверки

```bash
node tests/sim.js        # тысячи партий ИИ против ИИ: карты не теряются, партии всегда заканчиваются
node tests/balance.js    # доля побед над каждым соперником с разными талисманами
node tests/runsim.js 500 0.75   # 500 целых забегов игроком с «умом» 0.75
```

Баланс на момент сборки (`runsim`, 500 забегов):

| Игрок | Проходит забег целиком | Выигрывает партий |
|---|---|---|
| сильный (ум 0.75) | 47% | 66% |
| средний (ум 0.5) | 27% | 59% |

Без талисманов сильный игрок обыгрывает Витька примерно в 75% партий, а финального Хозяина — примерно в 30%. Симуляция не умеет применять фокусы и активные талисманы, поэтому живому игроку будет немного легче.

## Сохранения

Прогресс хранится в `localStorage` браузера: текущий забег, статистика и открытые рубашки. Забег сохраняется перед каждым столом и в барахолке. Если выйти посреди партии, стол начнётся заново.

## Что нужно для Яндекс Игр

Вся работа с площадкой собрана в одном объекте `Platform` в начале `src/run.js`, поэтому SDK подключается только там:

1. Подключить Yandex Games SDK. После загрузки вызвать `ysdk.features.LoadingAPI.ready()` (это `Platform.ready`), во время партии — `GameplayAPI.start/stop` (`Platform.gameplayStart/Stop`).
2. Перевести сохранения на облачные: `player.getData/setData` вместо `localStorage` в `Platform.read/write`.
3. Реклама:
   - полноэкранная — между столами;
   - за вознаграждение — например, «+1 сердце» или «перемешать барахолку бесплатно».
4. Встроить шрифты в файл. Сейчас они грузятся с Google Fonts, а площадка может блокировать внешние запросы; без них игра работает, но со стандартными шрифтами.
5. Подготовить иконку, обложку, скриншоты и описание для каталога.
